# 國立臺南大學附屬高級中學 (TNTCSH) — 3D 互動校園導覽地圖

以 **Three.js (WebGL)** 打造的國立南大附中全區 3D 互動校園導覽系統，提供校園 30+ 棟建築外觀、分層平面配置圖（1F～4F 逐層拆解）、處室／教室／專科教室關鍵字即時搜尋，以及 A 到 B 校園雙點尋路導航功能。

## ✨ 主要功能

- **🏫 全校 3D 建築與地標導覽**：涵蓋行政大樓、教學區（正德樓、利用樓、厚生樓、樂耕樓、圖書館、科學館）、實習工坊與專科館、體育場館及學生宿舍等 30+ 處校園建築與地標。
- **🏢 1F～4F 樓層立體拆解檢視**：點選任意建築物後，可於右側面板切換 **3D 樓層拆解** 與 **2D 平面配置圖**，快速查看各樓層處室、班級教室、實驗室、廁所與樓梯動線。
- **🔍 處室／班級／設施智慧搜尋**：支援搜尋「校長室」、「教務處」、「301」、「烘焙」、「健康中心」等關鍵字，一鍵飛越定位至所屬建築與樓層。
- **🧭 校園 A → B 路線導航**：選擇起點與終點建築，自動繪製 3D 發光導航路徑並估算步行距離與時間。
- **✋ 直覺視角操控**：支援滑鼠左鍵拖曳平移、右鍵旋轉、滾輪縮放、畫面右下角方向鍵與「🏠 最佳全覽視角」一鍵置中。

## 🚀 線上瀏覽與部署

本專案為純前端靜態網頁（Zero-build），無須後端伺服器即可直接部署於 **GitHub Pages** 或 **Vercel**：

- **GitHub Pages**：於儲存庫 `Settings` → `Pages` → `Build and deployment` 選擇 `Deploy from a branch`（`main` / `/ (root)`）即可發佈。
- **本機預覽**：
  ```bash
  python -m http.server 8080
  ```
  接著於瀏覽器開啟 `http://localhost:8080`。
